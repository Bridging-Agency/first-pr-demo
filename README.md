# first-pr-demo

Dieses Repository wurde von Bridging-Agency erstellt um den ersten Pull Request auf GitHub zu üben.

## Was ist ein Pull Request?

Ein Pull Request (PR) ist ein Vorschlag, Änderungen in ein Repository einzufügen.
So funktioniert die Zusammenarbeit auf GitHub: jeder macht seine Änderungen auf einem eigenen Branch
und schlägt sie dann als PR vor.

## Schritte

1. Repository klonen
2. Branch erstellen
3. Änderungen machen
4. PR öffnen
